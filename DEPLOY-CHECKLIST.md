# Quick deployment checklist

- [ ] Create Supabase project
- [ ] Run `supabase/schema.sql` in SQL Editor
- [ ] Push DropShare folder contents to GitHub
- [ ] Import repository into Vercel
- [ ] Add `NEXT_PUBLIC_SUPABASE_URL`
- [ ] Add `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- [ ] Add `NEXT_PUBLIC_STORAGE_BUCKET` = `shared-media`
- [ ] Deploy, upload a small test photo, and open its link in a private/incognito browser
- [ ] Before public promotion, add CAPTCHA/rate limits and an abuse reporting/removal path
